Nouveau projet: sur le serveur distant ( origin ) ?
   https://github.com/new
Nommer le projet ?
Ajouter un dépôt distant ?
  Dépot local ( .git ) ↔ dépot distant ( nom et adresse-du-dépôt ) git remote add origin [url-dépôt-distant]
Récupèrer un dépôt distant ? Si tu n'as pas le projet(en local): Récupère tout le projet
git clone <URL_DU_REPO>

Si tu n'as pas le projet(en local): Récupère seulement b2
git clone --branch    b2    --single-branch <URL_DU_REPO>
Renommer un dépôt( local et distant ) ? ✅Renommer le dépôt local
mv etacivil23 etatcivil2.3

✅Renommer le depôt distant(github)
Settings/ Repository name (et tu change le nom)

✅Mettre à jour l’URL du remote dans ton dépôt local
   Place‑toi dans le dossier du dépôt local (le nouveau nom), puis exécute:
git remote set-url origin https://github.com/TON_USER/NOUVEAU_NOM.git

Tu peux vérifier que tout est bon avec :
git remote -v
Difféfference entre pull et clone ? pull : Mise à jour dépôt local(Récupère et merge)

clone : Nouveau dépôt local
Difféfference entre pull et fetch ? pull : Récupère et merge

fetch : Récupère sans merger

Push/Pull et Fetch


Pousser la branche b2 ( vers le remote ) ? git push    -u    origin    b2
Récuperer la branche b2 ? Si tu as le projet(en local): Se positionner sur b2 et faire
git pull    nom-repertoire-distant    nom-branche  

Si tu as le projet(en local) mais tu n'as pas la branche b2
git fetch    origin    b2:b2

Difféfference entre pull et fetch ? pull : Récupère et merge

fetch : Récupère sans merge
